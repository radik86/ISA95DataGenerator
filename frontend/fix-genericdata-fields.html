Fix GenericDataStores Fields

Use this utility to patch field names or backfill missing fields in the GenericDataStores SQL Server table via the REST API. Make sure the API is running at http://localhost:5237.


1 — Fix field renames (plannedDurationHours / actualDurationHours)

Renames plannedDurationHours → plannedQuantity in segmentEquipmentRequirements and actualDurationHours → actualQuantity in segmentEquipmentActuals. Only records that still have the old name are touched.

2 — Backfill operationsType

Adds operationsType to all process-data store records that are missing it. Records whose id starts with MNT- are tagged "Maintenance"; everything else gets "Production".

3 — Custom field rename

Rename any field across all records in a chosen store.



4 — Run all fixes

Runs sections 1 and 2 in sequence (field renames + operationsType backfill).
